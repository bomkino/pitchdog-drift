# Drift V2 requirement and phase matrix

Updated: 23 August 2026

Branch: `codex/v2-directors-cut`

This is the public scope map for the integrated V2 candidate. `implemented`, `tested`, `committed`, `packaged`, `installed`, `pushed`, `merged`, `released`, and `approved` remain separate states.

## Authority

1. Project V4 owns saved creative truth.
2. One explicit authored clock owns preview and export evaluation.
3. One Three.js/WebGL2 graph draws preview, stills, sequences, and MP4 frames.
4. One semantic event spine drives visual action and optional tactile sound.
5. One final output transform owns global optics and colour.
6. V1 compatibility remains inert until an explicit V2 World transaction.

Feature flags describe build or session capability. They never become hidden creative truth.

## Non-negotiable checks

- V1 pixels and `/Applications/Drift.app` stay unchanged until a separately authorized production transition.
- Export uses exact frame identity, not wall-clock history or accumulated preview state.
- Unsupported or future project input fails without replacing the open project.
- Every effect has an honest zero or bypass.
- Transparent output remains alpha-correct; opaque output cannot leak transparent edges.
- Grain stays in the world, never on imported slides or protected presenter pixels.
- Sound remains opt-in and local; there are no runtime network requests.
- Presenter media is protected from accidental material, light, lens, grain, or audio contamination.
- Resources are bounded and disposed; cancellation cannot present partial output as success.
- Visual taste, listening taste, package integrity, installation, CI, merge, and release are distinct approvals.

## Scope exclusions

- No React Three Fiber, GSAP, WebGPU/TSL, general physics engine, second renderer, second timeline, or second project model.
- No public binary distribution before third-party compliance, Developer ID signing, notarisation, Gatekeeper verification, and explicit publication authority.
- No claim that visual or sonic taste is objectively proven by unit tests.
