# Sound design

Pitchdog Drift treats sound as movement material, not background music. The sound layer is original procedural Foley generated by the application at 48 kHz. It ships no borrowed samples, trackers, network calls, or opaque sound packs.

## Editorial language

The six characters are structural starting points rather than genre presets:

- **Paper** — fibre, page travel, dry editorial movement.
- **Air** — displaced air and long, soft tails.
- **Celluloid** — sprocket detail, flutter and restrained mechanism.
- **Glass** — precise resonances and clean accents.
- **Felt** — muted weight with almost no hard transient.
- **Mechanism** — tactile clicks, ratchets and compact impacts.

Each character is synthesized from deterministic noise, resonators, transient envelopes and low-frequency weight. The controls alter the synthesis itself, not a post-hoc sample-player skin.

## Determinism

The renderer uses a seeded integer PRNG. Cue timing, jitter, stereo placement, texture and dither all derive from the saved seed. A fixed settings object and duration therefore produce the same PCM checksum on every run.

The master path:

1. Derive editorial cue times from duration, motion tempo, slide count and density.
2. Render each cue directly into a fixed-size stereo buffer.
3. Wrap tails at the loop boundary when seamless looping is enabled.
4. Apply bounded soft limiting.
5. Export 24-bit stereo PCM WAV with deterministic TPDF dither.

No `AudioContext.currentTime`, animation frame, wall clock or microphone recording enters the master renderer.

## Live interaction

The preview runtime unlocks only after a user gesture. It adds restrained cues to stage drag, wheel travel, control changes and release/settle actions. Polyphony and trigger rate are bounded to keep rapid scrubbing from turning into noise.

Preview can be disabled independently. Automatic cues are silenced when the operating system requests reduced motion, unless the user explicitly changes that policy.

## Voice

`Voice duck` reserves headroom for presenter audio. It is an authored mix intent, not a claim that every voice should be buried under decorative sound. The default is conservative.
