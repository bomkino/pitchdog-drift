# Mega Main construction contract

Frozen for `integration/mega-main-native`.

## Goal

Build Drift 1.0 as a standalone, local-first Mac directing instrument for turning pitch-deck slides and one optional presenter video into authored, verified moving-image sequences.

Mega Main is not a mechanical merge of the experimental branches. Those branches are donors: algorithms, presets, tests, failure contracts, assets and research. Every accepted capability is re-authored behind one project model, one timeline, one render graph, one semantic event spine and one native platform boundary.

## Non-negotiable invariants

1. `main` remains untouched until one exact release candidate passes the complete gauntlet.
2. The packaged Mac application is tested in every wave; the browser is a development and regression surface, not the architectural authority.
3. Preview and export evaluate the same saved project at explicit time.
4. A feature does not graduate until preview, still, PNG sequence, MP4 and the packaged Mac app agree where applicable.
5. AppKit owns windows, documents, Finder permissions, staged writes, recovery, native AAC, signing and packaging. TypeScript owns project meaning and scene evaluation. Neither creates a second renderer or timeline.
6. User media stays local. Drift ships no analytics, cloud upload, updater daemon, remote font, local server or hidden network path.
7. Save, recovery and export are distinct promises. No status says saved or complete before the relevant atomic commit and verification finish.
8. Old projects are migrated through validated candidate state. Opening or migration failure leaves current work intact.
9. CI may build, test and preserve failure receipts. It may not generate product source, commit fixes, mutate branches or publish binaries.
10. No donor capability disappears without an explicit parity disposition.

## Immediate construction order

1. Freeze donor evidence and architecture decisions.
2. Repair the signed packaged application bootstrap.
3. Establish the project/revision/command chassis.
4. Build Project V3 and real native document semantics.
5. Decompose renderer and exporter.
6. Integrate temporal direction, space, matter, light, atmosphere, lens and sound in that dependency order.
7. Compile worlds from the resolved domains.
8. Run donor parity, chaos, performance, accessibility and human taste gauntlets.
9. Sign, notarize and verify one exact Drift 1.0 release candidate.

## Stop condition

Mega Main is done only when two consecutive adversarial passes produce no accepted material improvement and the exact candidate intended for `main` has passed packaged-app, migration, output, security, physical-hardware and human-review gates.
