# Drift native product contract

Drift is an Apple-silicon Mac directing instrument with native document/UI/media/render/output ownership. The installed runtime contains no WebKit or browser engine. Preserve the authored eight Worlds, 72 variants, motion paths, cadence, materials, lighting, optics and licensed recorded sound.

The initial canvas is exactly 2576 × 1080. Ratios use exact arithmetic; preview scale, World and Recut never alter output dimensions. Native Light/Dark appearance changes interface chrome only.

Pin, Spotlight and Closing are independent. Source trim/speed/loop has its own clock. A finite presentation has one Closing after all repeats; Loop disables Closing use while retaining its assignment. Source-video audio remains silent.

Native `.pitched` is a new strict ZIP64 format preserving original bytes. No legacy migration or hidden transcoding. Imports, document replacement, Save/Save As, recovery, Undo/Redo and close decisions must preserve ownership and prior accepted content on failure. Export owns an immutable source snapshot across document changes.

Preview and export share the same native frame plan. PNG supports alpha; MP4 requires explicit opaque output. Success requires decoded dimensions, frames, timestamps and requested audio. Cancellation and errors preserve existing destinations. Caches and decode work remain bounded without reducing originals.

Only exact-main tested native bytes may become a public installer. Main protection, published assets, immutable tags, licenses, signing disclosure and user projects are not negotiable shortcuts. Hardware observations and unavailable tests must be identified separately from automated proof.
